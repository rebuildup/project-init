# ADR-0012: Fix OpenCode Go routes and stop automatic OpenRouter free selection

- Status: Accepted
- Date: 2026-11-01
- Related: issue #76, supersedes issue #72 / draft PR #73, ADR-0008

## Context

The launcher already supports explicit harness × provider routes from
`config/agents.toml` with fail-closed model validation. Two separate problems
remained:

1. **OpenCode Go** ($10/month) was not usable through the launcher, although
   Claude Code and Pi both support it. Both harnesses normally read
   `OPENCODE_API_KEY`, which is also the key for OpenCode Zen. A naive route
   would either reuse the ambient Zen key or silently fall back to it when the
   Go secret is missing. Go is also a subscription allowance, not the
   pay-as-you-go Console balance, so an implicit overflow path is a billing
   risk.
2. **OpenRouter free** had an in-progress automatic selection system
   (availability/quality gates, catalog cache, evaluator, calibration) on
   issue #72 / PR #73. Real evaluation never qualified all three harnesses,
   local results contradicted public benchmark expectations, and the extra
   machinery made an auxiliary free route harder to reason about than the
   routes it served.

## Decision

1. Add exactly two Go routes, with fixed defaults in TOML:
   - `claude.opencode-go` → `deepseek-v4.1-flash`,
     `https://opencode.ai/inference/go/anthropic`, Go key as
     `ANTHROPIC_AUTH_TOKEN`.
   - `pi.opencode-go` → `mimo-v2.6-flash`, Pi's native `opencode-go` provider,
     Go key as `OPENCODE_API_KEY`.
   `opencode.opencode-go` is deliberately not added now.
2. Add `secret_only = true` for providers whose harness env name is shared
   with another product. For such a provider the named Infisical secret is the
   only accepted source: the ambient env value is ignored and overwritten, the
   fast path only applies when the secret name itself is set, and a missing
   secret fails before the harness starts. `secret_only` requires distinct
   `secret` and `env` names.
3. The normal `openrouter-free` routes accept one fixed model id
   (`nvidia/nemotron-3-ultra-550b-a55b:free`). No runtime catalog scan,
   availability/quality gate, meta-router, cache or fallback is in the launch
   path. Changing the model is a reviewed TOML edit.
4. Do not merge PR #73's evaluator/catalog/quality code, and do not add a new
   harness, daemon, proxy or resident router. Preserve the research evidence
   as documentation only.
5. No implicit model/provider switching, billing fallback or session
   migration. Provider quota, privacy-region and Extra Usage settings are
   documented operator prerequisites; the launcher never claims to change
   them.

## Consequences

- Go and Zen keys cannot cross-contaminate through the launcher's environment
  handling. A missing `OPENCODE_GO_API_KEY` produces a clear failure rather
  than a Zen-key request.
- Go routes remain **unverified against the real API** until the Infisical
  `dev` environment contains `OPENCODE_GO_API_KEY`. Mock coverage and the
  public model catalog are not treated as proof of inference.
- DeepSeek V4.1 Flash requires the Go workspace privacy region `Global`;
  without it the route is blocked, not silently remapped.
- Pi prefers `~/.pi/agent/auth.json` over environment variables and
  `models.json` can replace provider endpoints. `secret_only` Pi routes
  therefore fail closed before launch when an `opencode-go` auth entry or
  provider override exists; those files are never edited or deleted.
- In Claude Code 2.1.314 the injected Anthropic env token took precedence over
  an existing claude.ai login (observed on the free route), but Go-specific
  billing remains unverified until a Go key exists.
- The single free allowlist prevents selecting another id; it does not detect
  the selected id becoming paid or being retired. Pricing/availability must be
  re-checked, with an account-side spend limit (hard cap, not merely an alert)
  as the hard stop.
- The free route is cheap but weaker than paid routes: it passed short
  response + tool calls on all three harnesses on 2026-11-01, while the longer
  Pi fixture in the salvaged research exhausted its request budget without a
  passing grade. It is not a quality claim.
