# ADR-0013: Infisical device definitions and native SSH / Herdr connections

- Status: Accepted for implementation; real UI acceptance remains separate
- Related: #78; reset decision at `ca412d9`

Each device owns its SSH host identity, local client private key, and actual Herdr
server/session. Infisical `/devices` in the existing dotfiles project `dev` owns
logical ID, OS/user, instance ID, SSH host/port/public host key and session. One
shared entry per node permits updating or deleting a WSL instance without
rewriting another device's definition. Existing application secrets are not read.

The `devices` CLI uses existing Bun tooling to validate definitions, generate
strict OpenSSH entries, verify the remote OS/user/instance, and call official
Herdr machine commands. It implements no transport, terminal sharing, gateway,
worker, VPN controller, or background synchronization service. Local remains
local; all workspace/tab state comes from the selected node's real session.

Creating/replacing/removing a device changes Infisical first, then each client
runs sync. A replacement must have its own host key. Invalid identity and offline
nodes fail explicitly. Ordinary Herdr reconnect uses the last synchronized host
key and session; it does not query Infisical itself. No claim of immediate global
revocation is made. SSH authorization and Infisical read permissions remain
separate; removing a definition does not revoke a previously authorized key.

Only profiles created by this CLI may be reconciled automatically. Foreign
profiles, running terminals, user work, and login caches are preserved. A missing
remote session must first be started locally, preventing accidental elevated
Windows server creation over SSH. Standard OS SSH setup belongs to pc-setup.

The retired implementation and PR #75 are not dependencies. Existing working
network routes can be used while obsolete resources are separately inspected;
new definitions do not depend on retired node/controller metadata. API tests and
CI are supplementary evidence, never proof of normal-screen input/output.
